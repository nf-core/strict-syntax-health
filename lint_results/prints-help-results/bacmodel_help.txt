Input/output options
  --input                     [string] Path to comma-separated or tab-separated file containing information about the samples in the 
experiment.  
  --outdir                    [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                     [string] Email address for completion summary. 

Generic options
  --help                      [boolean, string] Display the help message. 
  --help_full                 [boolean]         Display the full detailed help message. 
  --show_hidden               [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided). 
 

Annotation options
  --annotation_tool           [string]  Tool to use for genome annotation  (accepted: prokka, bakta) [default: prokka] 
  --baktadb                   [string]  Directory to cache the Bakta database in (only used when `annotation_tool`='bakta'). Downloaded 
automatically on first use via Nextflow's storeDir and reused on subsequent runs, so most users 
never need to set this. [default: assets/bakta_db]  
  --baktadb_type              [string]  Bakta database type to download  (accepted: light, full) [default: light] 
  --min_contig_length         [integer] Minimum contig length for annotation and analysis [default: 200] 

Database options
  --pfamdb                    [string] Directory to cache the Pfam database in (only used when `skip_traitar`=false). Downloaded 
automatically on first use via Nextflow's storeDir and reused on subsequent runs, so most users 
never need to set this. [default: assets/pfam_db]  

Analysis options
  --skip_macsyfinder          [boolean] Skip MacSyFinder macromolecular systems detection [default: false] 
  --macsyfinder_models        [string]  MacSyFinder models to use (TXSS for Type III/IV/VI secretion systems) [default: TXSS] 
  --macsyfinder_db_type       [string]  MacSyFinder --db-type: 'unordered' for MAGs/draft assemblies with unreliable gene order (default, 
most permissive), 'ordered_replicon' for a single complete/nearly-complete genome (enables 
synteny-aware detection), or 'gembase' for multiple complete replicons in one gembase-formatted 
database  (accepted: unordered, ordered_replicon, gembase) [default: unordered]  
  --macsyfinder_db            [string]  Directory to cache downloaded MacSyFinder models in (one subdirectory per `macsyfinder_models` 
value). Downloaded automatically on first use via Nextflow's storeDir and reused on subsequent runs. 
[default: assets/macsyfinder_db]  
  --skip_traitar              [boolean] Skip TRAITAR phenotype prediction [default: false] 
  --skip_carveme              [boolean] Skip CarveMe genome-scale metabolic reconstruction [default: false] 
  --carveme_mediadb           [string]  Path to CarveMe media database TSV file (columns: medium, description, compound, name). If not 
provided, uses CarveMe's default media database. See assets/medium_carveme_mediadb_example.tsv for 
an example.  
  --skip_gapseq               [boolean] Skip Gapseq pathway analysis and metabolic modeling [default: true] 
  --gapseq_doall_args         [string]  Custom arguments for the simplified 'gapseq doall' search step (default: '-b 200 -A diamond'). Only 
used in the default doall workflow - ignored if any of the 
gapseq_find_args/gapseq_findtransport_args/gapseq_draft_args/gapseq_medium_args/gapseq_fill_args 
below are set, since that switches to the custom/stepwise workflow instead.  
  --gapseq_find_args          [string]  Custom arguments for 'gapseq find' (e.g., '-b 200 -A diamond') 
  --gapseq_findtransport_args [string]  Custom arguments for 'gapseq find-transport' (e.g., '-b 200') 
  --gapseq_draft_args         [string]  Custom arguments for 'gapseq draft' (e.g., '-u 200') 
  --gapseq_medium_args        [string]  Custom arguments for 'gapseq medium' 
  --gapseq_fill_args          [string]  Custom arguments for 'gapseq fill' (e.g., '-b 100') 
  --skip_memote               [boolean] Skip MEMOTE metabolic model quality evaluation (only runs when skip_gapseq=false or 
skip_carveme=false) [default: true]
