Typical pipeline command:

  nextflow run nf-core/pixelator -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                                                   [string] Path to comma-separated file containing information about the samples in the experiment. 
  --input_basedir                                           [string] Path to a local or remote directory that is the "current working directory" for relative paths 
defined in the input samplesheet  
  --outdir                                                  [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                                                   [string] Email address for completion summary. 

Edgelist options
  --pna_edgelist_mismatch_threshold                         [integer] Allow this many mismatches when matching marker barcodes. [default: 0] 
  --pna_edgelist_min_avg_quality                            [integer] Drop reads whose average quality in marker and UMI regions is below this. [default: 20] 
  --pna_edgelist_max_umi_base_freq                          [number]  Drop low-complexity UMIs where one base makes up more than this fraction of the UMI. [default: 
0.8]  
  --pna_edgelist_lbs_overlap_max_edits                      [integer] Drop reads whose UMI aligns to any substring of an assay LBS (or its reverse complement) within this 
many edits (Levenshtein distance). [default: 6]  
  --save_pna_edgelist_reads                                 [boolean] Save the intermediate per-read edgelist parquet file generated from the raw input reads. 
  --save_pna_edgelist_dropped_reads                         [boolean] Save the reads that were dropped by the edgelist step, with the reason they were dropped. 

Aggregate options
  --save_pna_aggregate_reads                                [boolean] Save the aggregated molecule-level parquet file. 

Graph options
  --save_pna_graph_pixelfile                                [boolean] Save the PXL dataset after the graph stage. 
  --pna_graph_multiplet_recovery                            [boolean] Activate the multiplet recovery using leiden community detection [default: true] 
  --pna_graph_initial_stage_leiden_resolution               [number]  The resolution parameter for the leiden algorithm at the initial stage. [default: 1.0] 
  --pna_graph_refinement_stage_leiden_resolution            [number]  The resolution parameter for the leiden algorithm at the refinement stage. [default: 0.5] 
  --pna_graph_edge_cycle_verification                       [boolean] Activate edge cycle verification to remove edges from well connected regions that are not part of 
cycles in the graph. [default: true]  
  --pna_graph_min_count                                     [number]  Discard edges with a read count below given value. Set to 1 to disable filtering. [default: 1.0] 
 
  --pna_graph_max_refinement_recursion_depth                [integer] The maximum recursion depth for the refinement algorithm. Set to 1 to disable refinement. 
[default: 3]  
  --pna_graph_initial_stage_max_edges_to_remove             [integer] The maximum number of edges to remove between components during the initial stage (iteration == 0) 
of multiplet recovery. [default: 10]  
  --pna_graph_refinement_stage_max_edges_to_remove          [integer] The maximum number of edges to remove between components during the refinement stage (iteration > 0) 
of multiplet recovery. [default: 20]  
  --pna_graph_initial_stage_max_edges_to_remove_relative    [number]  The maximum number of edges to remove between two components relative to the number of nodes in the 
smaller of the two when during the initial stage (iteration == 0) of multiplet recovery.  
  --pna_graph_refinement_stage_max_edges_to_remove_relative [number]  The maximum number of edges to remove between two components relative to the number of nodes in the 
smaller of the two when during the refinement stage (iteration > 0) of multiplet recovery.  
  --pna_graph_component_size_min_threshold                  [integer] Components with fewer nodes than this will be filtered from the output data. Set to null to enable 
automatic size filtering based on the data. [default: 8000]  
  --pna_graph_component_size_max_threshold                  [integer] Components with more nodes than this will be filtered from the output data. Set to null to enable 
automatic size filtering based on the data. [default: 1000000]  

Graph-collapse options
  --skip_graph_collapse                                     [boolean] Skip graph-collapse step 
  --save_pna_graph_collapse_pixelfile                       [boolean] Save the PXL dataset after the graph-collapse stage. 
  --pna_graph_collapse_bfs_distance                         [integer] Maximum number of hops from a searched node to look for a same-marker, same-role collapse candidate. 
[default: 6]  
  --pna_graph_collapse_hamming_threshold                    [integer] Maximum Hamming distance (inclusive) between a searched node's UMI and a candidate's UMI for the 
node to be collapsed into that candidate. [default: 2]  
  --pna_graph_collapse_max_degree                           [integer] Search a node for a collapse target only when its degree is at most this value. 1 investigates only 
leaves. [default: 1]  
  --pna_graph_collapse_report_collapsed_sequences           [boolean] Also write a TSV file listing the component, original UMI and corrected UMI of every collapsed node. 
 

Sample calling options
  --save_pna_sample_calling_pixelfile                       [boolean] Save the PXL dataset after the sample calling stage. 
  --pna_sample_calling_save_undetermined                    [boolean] Save components that could not be confidently assigned to any sample to a separate pxl file. 
 
  --pna_sample_calling_remove_incompatible                  [boolean] Remove antibodies that are incompatible with their component's called sample. [default: true] 
 
  --pna_sample_calling_enrichment_threshold                 [number]  Enrichment threshold for sample calling. [default: 10.0] 

Denoise options
  --skip_denoise                                            [boolean] Skip denoise step 
  --save_pna_denoise_pixelfile                              [boolean] Save the PXL dataset after the denoise stage. 
  --pna_denoise_run_one_core_graph_denoising                [boolean] Activate the one-core graph denoising algorithm 
  --pna_denoise_pval_threshold                              [number]  The p-value threshold for the a marker to be considered significantly over-expressed in the one-core 
layer of a component [default: 0.05]  
  --pna_denoise_inflate_factor                              [number]  The inflate factor for the number of nodes from over-expressed markers to be removed from the 
one-core layer of a component [default: 1.5]  
  --pna_denoise_run_ace_denoising                           [boolean] Remove nodes in the peripheral-like partition using adaptive core expansion (ACE). [default: 
true]  
  --pna_denoise_ace_k                                       [integer] Neighborhood radius in graph steps for ACE denoising. [default: 3] 
  --pna_denoise_run_pls_denoising                           [boolean] Run PLS-on-coreness denoising and retain the largest connected component after filtering. 
[default: true]  
  --pna_denoise_pls_score_threshold                         [number]  All retained PLS score columns must exceed this value. [default: -3.0] 

Analysis options
  --skip_analysis                                           [boolean] Skip analysis step 
  --pna_analysis_compute_proximity                          [boolean] Compute proximity scores [default: true] 
  --pna_analysis_compute_k_cores                            [boolean] Compute k-core summary tables for each component [default: true] 
  --pna_analysis_compute_svd_var_explained                  [boolean] Compute the variance explained by the SVD components [default: true] 
  --pna_analysis_svd_nbr_of_pivots                          [integer] Number of pivots to use for the SVD decomposition [default: 50] 

Experiment Summary options
  --skip_experiment_summary                                 [boolean] Skip experiment summary generation 

Global options
  --pixelator_container                                     [string]  Override the container image reference to use for all steps using the `pixelator` command. 
  --experiment_summary_container                            [string]  Override the container image to use for the experiment summary step. 
  --save_all                                                [boolean] Save all intermediate results. 
  --save_json                                               [boolean] Save all JSON report and metadata files generated by pixelator. [default: true] 
  --technology                                              [string]  The technology used to process the samples  (accepted: proxiome-v1, proxiome-v2, hashed_samples, 
nonhashed_samples)  

Generic options
  --help                                                    [boolean, string] Display the help message. 
  --help_full                                               [boolean]         Display the full detailed help message. 
  --show_hidden                                             [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
