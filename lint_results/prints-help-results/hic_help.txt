Typical pipeline command:

  nextflow run nf-core/hic -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                         [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                        [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                         [string] Email address for completion summary. 
  --multiqc_title                 [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Reference genome options
  --genome                        [string] Name of iGenomes reference. 
  --fasta                         [string] Path to FASTA genome file. 
  --bwt2_index                    [string] Full path to directory containing Bowtie index 
  --bwa_index                     [string] Full path to directory containing Bwa-mem index 

Hi-C processing
  --processing                    [string] Hi-C processing method  (accepted: hicpro, pairtools) [default: hicpro] 

Digestion Hi-C
  --digestion                     [string]  Name of restriction enzyme to automatically set the restriction_site and ligation_site options 
(hindiii, mboi, dpnii, arima)  (accepted: hindiii, mboi, dpnii, arima, arimaV2)  
  --restriction_site              [string]  Restriction motifs used during digestion. Several motifs (comma separated) can be provided. 
  --ligation_site                 [string]  Expected motif after DNA ligation.  Several motifs (comma separated) can be provided. 
  --chromosome_size               [string]  Full path to file specifying chromosome sizes (tab separated with chromosome name and size)`. 
 
  --restriction_fragments         [string]  Full path to restriction fragment (bed) file. 
  --save_reference                [boolean] If generated by the pipeline save the annotation and indexes in the results directory. 

Micro-C/DNAse Hi-C
  --no_digestion                  [boolean] For Hi-C protocols which are not based on enzyme digestion such as DNAse Hi-C or Micro-C 
  --min_cis_dist                  [integer] Minimum distance between loci to consider. Useful for --no-digestion mode to remove spurious 
ligation products. Only values > 0 are considered  

Alignments
  --split_fastq                   [boolean] Split the reads into chunks before running the pipelne 
  --fastq_chunks_size             [integer] Read number per chunks if split_fastq is used [default: 20000000] 
  --min_mapq                      [integer] Keep aligned reads with a minimum quality value [default: 10] 
  --bwt2_opts_end2end             [string]  Option for HiC-Pro end-to-end bowtie mapping [default: --very-sensitive --end-to-end --reorder] 
 
  --bwt2_opts_trimmed             [string]  Option for HiC-Pro trimmed reads mapping [default: --very-sensitive --end-to-end --reorder] 
  --bwa_opts                      [string]  Option for Bwa-mem mapping [default: -5SP -T0] 
  --save_aligned_intermediates    [boolean] Save all BAM files during two-steps mapping 

Valid Pairs Detection
  --keep_dups                     [boolean] Keep duplicated reads 
  --keep_multi                    [boolean] Keep multi-aligned reads 
  --max_insert_size               [integer] Maximum fragment size to consider. Only values > 0 are considered 
  --min_insert_size               [integer] Minimum fragment size to consider. Only values > 0 are considered 
  --max_restriction_fragment_size [integer] Maximum restriction fragment size to consider. Only values > 0 are considered 
  --min_restriction_fragment_size [integer] Minimum restriction fragment size to consider. Only values > 0 are considered 
  --pairtools_parse_opts          [string]  Update 'pairtools parse' options [default: --walks-policy 5unique] 
  --save_interaction_bam          [boolean] Save a BAM file where all reads are flagged by their interaction classes 
  --save_pairs_intermediates      [boolean] Save all types of non valid read pairs in distinct output files 

Contact maps
  --bin_size                      [string, integer] Resolution to build the maps (comma separated) [default: 1000000] 
  --hicpro_maps                   [boolean]         Generate raw and normalized contact maps with HiC-Pro 
  --ice_filter_low_count_perc     [number]          Filter low counts rows before HiC-Pro normalization [default: 0.02] 
  --ice_filter_high_count_perc    [integer]         Filter high counts rows before HiC-Pro normalization 
  --ice_eps                       [number]          Threshold for HiC-Pro ICE convergence [default: 0.1] 
  --ice_max_iter                  [integer]         Maximum number of iteraction for HiC-Pro ICE normalization [default: 100] 
  --balancing_opts                [string]          Update 'cooler balance' options [default: --force] 
  --res_zoomify                   [string, integer] Maximum resolution to build mcool file 
  --save_raw_maps                 [boolean]         Save raw contact maps 

Downstream Analysis
  --min_size                      [integer]        Minimum chromosome size to be retained. Useful for Calder2, which cannot be applied to chromosomes 
that do not have a sufficient number of bins. [default: 0]  
  --res_dist_decay                [string]         Resolution to build count/distance plot [default: 250000] 
  --tads_caller                   [string]         Define methods for TADs calling [default: insulation] 
  --compartments_caller           [string]         Define methods for compartments calling [default: cooltools] 
  --res_tads                      [string]         Resolution to run TADs callers (comma separated) [default: 40000] 
  --res_compartments              [string]         Resolution for compartments calling [default: 250000] 
  --loops_caller                  [string]         Call chromatin loops with 'fithichip' (HiChIP / PLAC-seq data) and/or 'hicexplorer' 
(hicDetectLoops), comma separated. Loops are not called when unset.  
  --res_loops                     [string]         Resolution(s) of the contact maps used for loop calling (comma separated) [default: 5000] 
  --loops_peaks                   [string]         BED file of 1D anchor peaks (e.g. ChIP-seq peaks of the HiChIP target) used by FitHiChIP. When 
unset, anchors are inferred from the valid pairs with MACS3.  
  --macs_gsize                    [number, string] Effective genome size for MACS3 peak calling: a number, scientific notation (e.g. 2.7e9 for human) 
or one of the MACS3 shortcuts hs, mm, ce, dm. Default: the total length of the chromosome sizes 
file.  
  --fithichip_lower_dist          [integer]        FitHiChIP: lower distance threshold (bp) of the interactions tested (LowDistThr) [default: 
20000]  
  --fithichip_upper_dist          [integer]        FitHiChIP: upper distance threshold (bp) of the interactions tested (UppDistThr) [default: 
2000000]  
  --fithichip_qvalue              [number]         FitHiChIP: FDR threshold of the significant interactions (QVALUE) [default: 0.01] 
  --fithichip_inttype             [integer]        FitHiChIP: interactions tested (IntType). 1 = peak-to-peak, 2 = peak-to-non-peak, 3 = peak-to-all, 4 
= all-to-all, 5 = every type  (accepted: 1, 2, 3, 4, 5) [default: 3]  
  --fithichip_bias                [integer]        FitHiChIP: bias regression (BiasType). Only 1 (coverage bias) is available: the ICE bias (2) runs 
HiC-Pro's ice, which the FitHiChIP container does not include.  (accepted: 1) [default: 1]  
  --fithichip_p2p_background      [boolean]        FitHiChIP: use the stringent peak-to-peak background (UseP2PBackgrnd, FitHiChIP(S)) instead of the 
loose background (FitHiChIP(L))  
  --maxloopdistance               [integer]        hicDetectLoops: Maximum genomic distance of a loop, usually loops are within a distance of ~2MB 
[default: 2000000]  
  --peakwidth                     [integer]        hicDetectLoops: The width of the peak region in bins. The square around the peak will include (2 * 
peakWidth)^2 bins [default: 2]  
  --windowsize                    [integer]        hicDetectLoops: The window size for the neighborhood region the peak is located in. All values from 
this region (exclude the values from the peak region) are tested against the peak region for 
significant difference. The square will have the size of (2 * windowSize)^2 bins [default: 5] 
 
  --pvaluepreselection            [number]         hicDetectLoops: Only candidates with p-values less the given threshold will be considered as 
candidates. For each genomic distance a negative binomial distribution is fitted and for each pixel 
a p-value given by the cumulative density function is given. This does NOT influence the p-value for 
the neighborhood testing. Can a single value or a threshold file created by hicCreateThresholdFile 
[default: 0.1]  
  --peakinteractionsthreshold     [integer]        hicDetectLoops: The minimum number of interactions a detected peaks needs to have to be considered 
[default: 10]  
  --obsexpthreshold               [number]         hicDetectLoops: The minimum number of obs/exp interactions a detected peaks needs to have to be 
considered [default: 1.5]  
  --pvalue                        [number]         hicDetectLoops: Rejection level for Anderson-Darling or Wilcoxon-rank sum test for H0. H0 is peak 
region and background have the same distribution [default: 0.025]  
  --expected                      [string]         hicDetectLoops: Method to compute the expected value per distance: Either the mean (mean), the mean 
of non-zero values (mean_nonzero) or the mean of non-zero values with ligation factor correction 
(mean_nonzero_ligation)  (accepted: mean, mean_nonzero, mean_nonzero_ligation) [default: mean] 
 
  --loop_plot_ytransform          [string]         hicPlotMatrix: transformation of the loop plot values  (accepted: log1p, log) [default: log1p] 
 
  --loop_plot_region              [string]         hicPlotMatrix: region of the loop plot, e.g. chr1:10000-20000. Whole genome when unset. 
  --loop_plot_region2             [string]         hicPlotMatrix: second region of the loop plot for inter-region contacts, used with 
--loop_plot_region  

Skip options
  --skip_fastqc                   [boolean] Do not perform FastQC 
  --skip_maps                     [boolean] Do not build contact maps 
  --skip_dist_decay               [boolean] Do not run distance/decay plot 
  --skip_tads                     [boolean] Do not run TADs calling 
  --skip_compartments             [boolean] Do not run compartments calling 
  --skip_balancing                [boolean] Do not run cooler balancing normalization 
  --skip_mcool                    [boolean] Do not generate mcool file for Higlass visualization 
  --skip_multiqc                  [boolean] Do not generate MultiQC report 

Generic options
  --multiqc_methods_description   [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                          [boolean, string] Display the help message. 
  --help_full                     [boolean]         Display the full detailed help message. 
  --show_hidden                   [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
