Input/output options
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Pipeline options
  --fasta                       [string]  Path to the genome FASTA file to annotate. 
  --mode                        [string]  Annotation mode: 'ensembl-vertebrates' (1 Mbp chunks), 'ensembl-invertebrates' (100 kbp chunks), 
'mgnify-assembly' (50 Mbp chunks, full Rfam, includes prokaryotic rRNA), or 'full' (1 Mbp chunks, 
full Rfam, eukaryotic only).  (accepted: ensembl-vertebrates, ensembl-invertebrates, 
mgnify-assembly, full)  
  --rfam_cm                     [string]  Path to the Rfam covariance model file (Rfam.cm). 
  --rfam_seed                   [string]  Path to the Rfam seed alignment file (Rfam.seed). 
  --rfam_accessions             [string]  Optional override for the Rfam accession list file. 
  --chunk_size                  [integer] Genome chunk size in base pairs for parallel cmsearch. 

Generic options
