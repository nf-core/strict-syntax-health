Input/output options
  --input                       [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Reference options
  --ref_fasta                   [string]  Reference genome FASTA matching the build (Ensembl primary assembly, contigs 1..MT), plain or 
bgzipped, with a .fai (and .gzi) index alongside. Required for variant (VCF) input unless 
--vep_download_cache is set.  
  --vep_cache                   [string]  Path to the VEP offline Ensembl cache. Either the cache directory or a `.tar.gz` of it. Required for 
variant input unless --vep_download_cache is set.  
  --vep_cache_version           [integer] VEP cache version, matching the downloaded cache (e.g. 116). Required for variant input. 
  --vep_species                 [string]  VEP species, matching the cache (e.g. homo_sapiens, mus_musculus). Required for variant input. 
 
  --vep_genome                  [string]  VEP assembly, matching the cache (e.g. GRCh38, GRCm39). Required for variant input. 
  --vep_download_cache          [boolean] Download the VEP cache and reference FASTA in-pipeline instead of providing --vep_cache/--ref_fasta. 
 

Peptide prediction options
  --peptide_col_name            [string]  Specifies the column name in the input file that contains the peptide sequences. [default: 
sequence]  
  --min_peptide_length_classI   [integer] Specifies the minimum peptide length for MHC class I peptides. [default: 8] 
  --max_peptide_length_classI   [integer] Specifies the maximum peptide length for MHC class I peptides. [default: 12] 
  --min_peptide_length_classII  [integer] Specifies the minimum peptide length for MHC class II peptides. [default: 8] 
  --max_peptide_length_classII  [integer] Specifies the maximum peptide length for MHC class II peptides. [default: 25] 
  --tools                       [string]  Specifies the prediction tool(s) to use. [default: mhcnuggets] 
  --wild_type                   [boolean] Also predict the wild-type counterparts of variant peptides. [default: false] 
  --proteome_reference          [string]  Optional reference proteome FASTA for self-filtering variant peptides. 
  --mutation_flanking_aas       [integer] Number of amino acids flanking the mutation on each side in the published variant protein FASTA 
(`variant_fasta/`); frameshifts run to the new stop. [default: 25]  
  --wide_format_output          [boolean] Specifies that the output file will be in wide format. [default: false] 
  --binder_only                 [boolean] Filter out non-binders from the final results. [default: false] 

Run optimisation
  --peptides_split_maxchunks    [integer] Specifies the maximum number of peptide chunks. [default: 100] 
  --peptides_split_minchunksize [integer] Specifies the minimum number of peptides that should be written into one chunk. [default: 5000] 
 

External software
  --netmhcpan_path              [string]  To use the 'netmhcpan' tool, specify the path to the original Linux software tarball for NetMHCpan 
4.2 here.  
  --netmhciipan_path            [string]  To use the 'netmhciipan' tool, specify the path to the original Linux software tarball for 
NetMHCIIpan 4.3 here.  
  --accept_mixmhcpred_license   [boolean] Confirm that you have read the MixMHCpred and MixMHC2pred licenses and use them for academic 
non-commercial research only. [default: false]  

Generic options
  --multiqc_methods_description [string]          Custom MultiQC yaml file containing HTML including a methods description.

  --help_full                   [boolean]         Display the full detailed help message.
