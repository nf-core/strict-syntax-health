Typical pipeline command:

  nextflow run nf-core/pacvar -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                       [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Annotation
  --skip_ensemblvep             [boolean] Option to skip SNVs annotation with Ensembl VEP. [default: false] 
  --vep_custom_args_snv         [string]  Add an extra custom argument to VEP. [default: --everything --filter_common --per_gene 
--total_length --offline --format vcf]  
  --vep_custom_args_sv          [string]  Add extra custom arguments to VEP for SV annotation. [default: --per_gene --buffer_size 5000 
--max_sv_size 250000000 --offline --format vcf]  
  --vep_custom_args_cnv         [string]  Add extra custom arguments to VEP for CNV annotation. [default: --per_gene --buffer_size 5000 
--max_sv_size 250000000 --offline --format vcf]  
  --outdir_vep_cache            [string]  Output directory where the downloaded VEP cache will be saved. Only used when `--download_vep_cache 
true`. Use absolute paths on cloud infrastructure. Note: when set, the cache is published outside 
`--outdir`.  
  --vep_out_format              [string]  VEP output-file format.  (accepted: json, tab, vcf) [default: vcf] 

Reference genome options
  --genome                      [string]  Name of iGenomes reference. 
  --fasta                       [string]  Path to FASTA genome or MMI file. 
  --fasta_fai                   [string]  Path to FASTA index 
  --dbsnp                       [string]  Path to dbsnp VCF file 
  --dbsnp_tbi                   [string]  Path to index file of the dbsnp VCF file 
  --dict                        [string]  Path to dict for variant calling 
  --download_vep_cache          [boolean] Download Ensembl VEP cache [default: false] 
  --vep_cache                   [string]  Path to VEP cache. [default: s3://annotation-cache/vep_cache/] 
  --vep_cache_version           [string]  VEP cache version. 
  --vep_genome                  [string]  VEP genome. 
  --vep_species                 [string]  VEP species. 

Variant Calling options
  --snv_caller                  [string]  The tool to use for calling SNP variants  (accepted: deepvariant, gatk4) [default: deepvariant] 
 
  --sv_caller                   [string]  The tool to use for calling structural variants  (accepted: pbsv, sawfish) [default: sawfish] 
 
  --skip_snp                    [boolean] Option to skip SNP variant calling [default: false] 
  --skip_sv                     [boolean] Option to skip SV variant calling [default: false] 
  --skip_hificnv                [boolean] Skip HiFiCNV copy number variant calling [default: false] 
  --skip_phase                  [boolean] Option to skip phasing [default: false] 
  --expected_cn                 [string]  BED/BED.GZ file specifying expected copy-number regions (for sawfish/hificnv). 
  --cnv_excluded_regions        [string]  BED/BED.GZ file of regions to exclude from CNV calling. 

Methylation profiling options
  --skip_cpg                    [boolean] Skip CpG site probability for 5mC methylation calling [default: false] 
  --skip_fiberseq               [boolean] Skip Fiber-seq nucleosome annotation with fibertools-rs [default: true] 
  --skip_m6A_predict            [boolean] Skip fibertools-rs m6A prediction and use existing m6A calls for Fiber-seq nucleosome annotation 
[default: true]  

Options specific to the repeat workflow
  --repeat_id                   [string] If no sample-specific repeat ID to be plotted is provided in the samplesheet, this value will be 
used   

Pre-processing options that are not workflow specific
  --barcodes                    [string]  Fasta file of barcodes 
  --skip_demultiplexing         [boolean] Option to skip demultiplexing 
  --intervals                   [string]  Path to BED file containing intervals for either variant calling or for repeat expansion 
characterization  

General workflow options
  --workflow                    [string] Option to choose which workflow type to run  (accepted: wgs, repeat) [default: wgs] 

Generic options
  --multiqc_methods_description [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                        [boolean, string] Display the help message. 
  --help_full                   [boolean]         Display the full detailed help message. 
  --show_hidden                 [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
