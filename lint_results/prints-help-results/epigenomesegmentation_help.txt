Input/output options
  --input                    [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                   [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                    [string] Email address for completion summary. 

EpiSegMix options
  --duration                 [boolean]         Run the duration HMM (DM) model to account for segment length. [default: false] 
  --dna                      [boolean]         Run the DNA methylation mode. [default: false] 
  --fitting                  [boolean]         Run the distribution fitting mode to find optimal statistical distributions. [default: false] 
 
  --counts                   [boolean]         Generate histone and/or methylation/coverage count files from the supplied BAM and BED inputs, then 
skip model training and segmentation. [default: false]  
  --jointrain                [boolean]         Train a shared model from the combined counts of the input samples for each requested state, then 
decode each sample separately. Disabled by default. [default: false]  
  --distributions            [string]          Comma-separated list of statistical distributions to test during 'fitting' mode (e.g., 
'NBI,P,ZINB'). [default: NBI,SI,BNB]  
  --binsize                  [integer]         Genomic bin size in base pairs used for discretising the genome. [default: 200] 
  --chromsizes               [string]          Path to a custom chromosome sizes file. 
  --methcounts               [string]          Path to a custom methylation counts file. 
  --histonecounts            [string]          Path to a custom histone counts file. 
  --states                   [integer, string] Number of chromatin states in the HMM model. [default: 8] 
  --decoding                 [string]          Decoding algorithm for inferring the most likely chromatin state sequence.  (accepted: viterbi, 
posterior) [default: viterbi]  
  --chr_parameter_estimation [string, integer] Chromosome used for initial parameter estimation. Specify by index or name. [default: 12] 

Reference genome options
  --genome                   [string] Name of reference genome. [default: hg38] 

Generic options

  --help_full                [boolean]         Display the full detailed help message. 
  --show_hidden              [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
