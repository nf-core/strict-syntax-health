Workflow options
  --trim_fastq                     [boolean] Trim adapter sequences with fastp. When false, fastp still generates QC output, but does not modify 
the reads. [default: true]  
  --publish_raw_fastq              [boolean] Whether to publish raw, untrimmed FASTQ files alongside trimmed FASTQ files. When false, only 
trimmed FASTQ files are published. [default: false]  
  --skip_tools                     [string]  Comma-separated list of tools to skip (fastp,fastqc,kraken,multiqc,checkqc,falco,md5sum,samshee) 
 
  --sample_size                    [integer] Number of reads to subsample for contamination detection. [default: 100000] 
  --kraken_db                      [string]  Path to the Kraken2 database used for contamination screening. 
  --json_schema_validator          [string]  JSON-formatted schema string passed to the samshee module for samplesheet validation. 
  --name_schema_validator          [string]  Schema name passed to the samshee module for samplesheet validation. 
  --file_schema_validator          [string]  Local JSON schema file passed to the samshee module for samplesheet validation. 
  --v1_schema                      [boolean] Whether the Illumina samplesheet is in v1 format. 

Input/output options
  --input                          [string]  Path to comma-separated file containing information about the samples in the experiment. 
  --flowcell_id                    [string]  Flowcell ID for single-flowcell runs. 
  --flowcell_samplesheet           [string]  Path to the flowcell SampleSheet.csv for single-flowcell runs. 
  --flowcell_lane                  [integer] Lane number for single-flowcell runs. 
  --flowcell_path                  [string]  Run directory (or tar.gz) for single-flowcell runs. 
  --flowcell_per_flowcell_manifest [string]  Per-flowcell manifest file for single-flowcell fqtk runs. 
  --outdir                         [string]  The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --optional_outputs               [boolean] Whether to publish optional outputs such as undetermined FASTQ files. 
  --email                          [string]  Email address for completion summary. 
  --multiqc_title                  [string]  MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Demultiplexing options
  --demultiplexer                  [string] Demultiplexer to use.  (accepted: bases2fastq, bcl2fastq, bclconvert, fqtk, sgdemux, mkfastq, 
mgikit) [default: bclconvert]  

Downstream CSV options
  --strandedness                   [string] Specifies the strandedness of RNA-Seq data for downstream sample sheet generation. This parameter 
does not affect the demultiplexing process but is used to generate the appropriate field in the 
nf-core/rnaseq samplesheet  (accepted: unstranded, auto, reverse, forward) [default: auto]  

CheckQC options
  --checkqc_config                 [string] Path to the checkqc config yml file. 

Generic options
  --multiqc_methods_description    [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --remove_samplesheet_adapter     [boolean]         Whether to remove adapter information from the Illumina samplesheet before demultiplexing. If it is 
present, demultiplexers may trim adapters during the demultiplexing step. [default: true]  
  --help                           [boolean, string] Display the help message. 
  --help_full                      [boolean]         Display the full detailed help message. 
  --show_hidden                    [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
