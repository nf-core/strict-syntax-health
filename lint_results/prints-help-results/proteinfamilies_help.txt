Typical pipeline command:

  nextflow run nf-core/proteinfamilies -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                                [string]  Path to comma-separated file '.csv' containing information about the samples in the experiment. 
 
  --outdir                               [string]  The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                                [string]  Email address for completion summary. Example: name.surname@example.com 
  --multiqc_title                        [string]  MultiQC report title. Printed as page header, used for filename if not otherwise specified. 
  --save_intermediates                   [boolean] Publish intermediate files under `intermediates/` (e.g. clustering databases, raw alignments and 
HMMs, search results).  

Generic options
  --multiqc_methods_description          [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                                 [boolean, string] Display the help message. 
  --help_full                            [boolean]         Display the full detailed help message. 
  --show_hidden                          [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided). 
 

Preprocessing parameters
  --skip_preprocessing                   [boolean] Skip all default QC steps for sequences (gap trimming, length filtering, validation, duplicate 
removal).  
  --min_seq_length                       [integer] The minimum allowed sequence length [default: 30] 
  --max_seq_length                       [integer] The maximum allowed sequence length [default: 5000] 
  --deduplicate_by                       [string]  How duplicate input sequences are found and removed.  (accepted: name, sequence) [default: name] 
 

Clustering parameters
  --clustering_tool                      [string]  Choose clustering algorithm. Either simple 'cluster' for medium size inputs, or 'linclust' for less 
sensitive clustering of larger datasets.  (accepted: linclust, cluster) [default: cluster]  
  --clustering_min_seq_identity          [number]  mmseqs parameter for minimum sequence identity [default: 0.3] 
  --clustering_min_coverage              [number]  mmseqs parameter for minimum sequence coverage ratio [default: 0.5] 
  --clustering_cov_mode                  [integer] mmseqs parameter for coverage mode: 0 for both, 1 for target and 2 for query sequence [default: 
0]  
  --clustering_min_cluster_size          [integer] Minimum clustering chunk size threshold to create seed Multiple Sequence Alignments upon. 
[default: 25]  

Family generation parameters
  --family_generation_algorithm          [string]  Choose the algorithm that turns clusters into family models. Either 'standard', aligning each 
cluster and building one HMM per task, or 'iterative', letting mgnifam loop HMM building, 
recruitment and realignment per cluster.  (accepted: standard, iterative) [default: standard] 
 
  --iterative_clusters_per_chunk         [integer] Number of clusters handed to each family generation task by the 'iterative' algorithm. [default: 
1000]  
  --alignment_tool                       [string]  Choose alignment tool. FAMSA is recommended as best time-memory-accuracy combination option.  
(accepted: famsa, mafft) [default: famsa]  
  --skip_update_refinement               [boolean] Keep the existing HMMs of updated families, only rebuilding their full MSAs. 

Seed MSA trimming parameters
  --seed_msa_trimming_ends_only          [boolean] Choose if ClipKIT should only clip gaps at the ends of the MSAs. [default: true] 
  --seed_msa_trimming_max_gap_fraction   [number]  Multiple Sequence Alignment (MSA) positions with gappiness greater than this threshold will be 
trimmed [default: 0.5]  

Recruiting and search parameters
  --search_evalue_cutoff                 [number] hmmsearch e-value cutoff threshold for reported results [default: 0.001] 
  --recruit_min_model_coverage           [number] hmmsearch minimum length percentage filter of hit env vs query length [default: 0.9] 

Family redundancy parameters
  --family_redundancy_removal            [string] Which families take part in the removal of between-family redundancy (hmmsearch of family 
representatives against family models).  (accepted: all, created_only, none) [default: all]  
  --family_merging                       [string] Which families can be merged with similar (but not redundant) families.  (accepted: all, 
created_only, none) [default: all]  
  --merged_family_name                   [string] Name of a merged family that holds updated families.  (accepted: existing, new) [default: 
existing]  
  --family_redundancy_min_model_coverage [number] hmmsearch minimum length percentage filter of hit env vs query length, for redundant family removal 
[default: 1.0]  
  --family_similarity_min_model_coverage [number] hmmsearch minimum length percentage of hit env vs query length, to flag and report similar families 
(and to optionally merge) [default: 0.9]  

Sequence redundancy parameters
  --seq_redundancy_min_seq_identity      [number]  mmseqs parameter for minimum sequence identity [default: 0.9] 
  --seq_redundancy_min_coverage          [number]  mmseqs parameter for minimum sequence coverage ratio [default: 0.9] 
  --seq_redundancy_cov_mode              [integer] mmseqs parameter for coverage mode: 0 for both, 1 for target and 2 for query sequence [default: 
0]
