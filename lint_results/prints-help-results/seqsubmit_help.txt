Typical pipeline command:

  nextflow run nf-core/seqsubmit -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                       [string] Path to samplesheet describing the data to be submitted (supported formats: csv, tsv, yaml, yml, 
json). Columns/fields depend on the pipeline mode  
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

rRNA and tRNA detection options
  --rrna_limit                  [number] Minimum percentage of 16S, 23S, and 5S rRNA gene length recovered to count the gene as present. 
[default: 80]  
  --trna_limit                  [number] Minimum number of tRNA genes detected to count tRNA as present. This value is defined by the 
MISAG/MIMAG standard and must not be modified. [default: 18]  

Assigning NCBI taxonomy with CAT_pack
  --cat_db                       Path to local CAT_pack DB 

Evaluation options
  --checkm2_db                            Path to pre-downloaded CheckM2 database. If omitted, downloads the version set by 
`--checkm2_db_download_id`  
  --checkm2_db_download_id      [integer] Zenodo ID for CheckM2 database download [default: 14897628] 

Generic options
  --multiqc_methods_description [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                        [boolean, string] Display the help message. 
  --help_full                   [boolean]         Display the full detailed help message. 
  --show_hidden                 [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided). 
 

Pipeline flow control parameters
  --centre_name                 [string]  Name of the submitter's organisation (mandatory for broker accounts). 
  --upload_tpa                  [boolean] Mark the assemblies as a Third PArty (TPA) [default: false] 
  --mode                        [string]  Type of the data to be submitted  (accepted: mags, bins, metagenomic_assemblies, reads) 
  --test_upload                 [boolean] Upload to ENA TEST server instead of LIVE server [default: true] 
  --is_private                  [boolean] Use that flag if you are referencing private data accessions in the samplesheet [default: false] 
 
  --release_date                [string]  Date (YYYY-MM-DD) until which the newly created study stays private in ENA. 
  --submission_study            [string]  ENA study accession (PRJ/ERP) to submit the data to 
  --study_metadata              [string]  Path to a file (JSON, CSV, or TSV) with metadata for registering a new ENA study. Required if 
--submission_study is not set.  
  --webincli_mode               [string]  Webin-CLI mode for ENA interaction: `submit` uploads data, `validate` performs validation only.  
(accepted: submit, validate) [default: submit]
