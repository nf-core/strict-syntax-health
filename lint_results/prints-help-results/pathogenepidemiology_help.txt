Pipeline input options
  --intervals                   [string]  Optional local uncompressed BED matching the query reference, used unchanged for core-read filtering 
and coverage and split by GATK into one calling BED per contig. Defaults to 
projectDir/assets/Pf3D7_core.bed; basename must be shell-safe.  
  --query_fasta                 [string]  Local query reference FASTA (.fa, .fasta or .fna, optionally gzipped), overriding queryurl. Reuses 
exact adjacent uncompressed-name FASTA, dictionary, minimap2 and complete BWA-MEM3 indexes; builds 
missing classes only. Basename must be shell-safe.  
  --host_fasta                  [string]  Local host reference FASTA (.fa, .fasta or .fna, optionally gzipped). Takes precedence over hosturl; 
no host indexes are required or built. Basename must start with an ASCII letter, digit or underscore 
and contain only ASCII letters, digits, dots, underscores and hyphens.  
  --queryurl                    [string]  URL of the query reference FASTA to download. 
  --hosturl                     [string]  URL of the host reference FASTA to download. 
  --threads                     [integer] Number of CPU threads to use per process. [default: 4] 

Input/output options
  --input                       [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Reference genome options
  --genome                      [string] Name of iGenomes reference. 
  --fasta                       [string] Path to FASTA genome file. 

Generic options
  --multiqc_methods_description [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                        [boolean, string] Display the help message. 
  --help_full                   [boolean]         Display the full detailed help message. 
  --show_hidden                 [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
