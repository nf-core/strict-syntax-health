Input/output options
  --input                       [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

ABO typing options
  --abo_reference_fasta         [string]  ABO reference FASTA (NG_006669.2, 42,144 bp) that reads are aligned to. 
  --abo_reference_fai           [string]  Index (.fai) of the ABO reference FASTA. 
  --abo_panel                   [string]  ABO diagnostic variant panel (positions, calling thresholds, ISBT allele associations). 
  --abo_bed                     [string]  Panel BED file used as a fallback for the panel-filtering step. 
  --abo_clair3_region_bed       [string]  BED file restricting Clair3 calling (and gVCF reference blocks) to the ABO exon 2-7 region. 
  --clair3_model_url            [string]  URL of the Clair3 PyTorch model files (`pileup.pt` and `full_alignment.pt`) for the sequencing 
chemistry used.  
  --renaming_file               [string]  Optional tab-delimited file mapping `sequencingID` to `sampleName` to rename samples in the final 
tables.  
  --skip_renaming               [boolean] Skip the optional sample renaming step. [default: true] 

Generic options
  --multiqc_methods_description [string] Custom MultiQC yaml file containing HTML including a methods description.
